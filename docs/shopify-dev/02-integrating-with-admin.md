# Integrating with the Shopify Admin

## Requirements
1. **Keep primary app workflows within Shopify**
   - Merchants should complete primary workflows without leaving admin
   - Exceptions: ad buying, ERP (too complex to embed fully)
   - Setup, configuration, dashboards MUST be in admin

2. **Enable seamless sign up based on Shopify credentials**
   - No additional login/sign-up prompt
   - Use merchant's existing Shopify credentials
   - Exceptions: B2B contracts, ad network connections

3. **Include simplified monitoring/reporting**
   - Expose key metrics on app home page
   - Simplified version of monitoring in admin

4. **Keep third-party connection settings within Shopify**
   - Any settings controlling Shopify-third-party connections must be in admin

## Eligibility for "Built for Shopify"
Apps that follow ALL best practices are eligible.

Source: https://shopify.dev/docs/apps/build/integrating-with-shopify
