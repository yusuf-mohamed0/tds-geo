# Color Tokens

Polaris provides CSS custom properties for colors. Key categories:

## Background Colors
- `--p-color-bg`: Default background (#f1f1f1 light, #1a1a1a dark)
- `--p-color-bg-surface`: Card/surface backgrounds
- `--p-color-bg-fill`: Button/filled element backgrounds
- `--p-color-bg-fill-brand`: Primary button backgrounds

## Text Colors
- `--p-color-text`: Default text
- `--p-color-text-secondary`: Secondary text
- `--p-color-text-disabled`: Disabled text
- `--p-color-text-link`: Link text

## Border Colors
- `--p-color-border`: Default border
- `--p-color-border-hover`: Hover border
- `--p-color-border-focus`: Focus ring

## Icon Colors
- `--p-color-icon`: Default icon
- `--p-color-icon-secondary`: Secondary icon
- `--p-color-icon-disabled`: Disabled icon

## Semantic Colors
- `--p-color-bg-fill-info`: Info (blue)
- `--p-color-bg-fill-success`: Success (green)
- `--p-color-bg-fill-warning`: Warning (yellow/orange)
- `--p-color-bg-fill-critical`: Critical (red)
- `--p-color-bg-fill-caution`: Caution (yellow)
- `--p-color-bg-fill-magic`: Magic/AI (purple)
