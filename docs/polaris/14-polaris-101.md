# Polaris 101

## What is Polaris?
Polaris is the design system for the Shopify admin - the shared language that guides how we build high-quality merchant experiences.

## Key Concepts
- **App Provider**: Required wrapper for Polaris components
- **Design Tokens**: CSS custom properties for color, space, typography
- **Components**: Reusable building blocks (Button, Card, Page, etc.)
- **Patterns**: Preferred solutions to common merchant goals
- **Icons**: 400+ commerce-focused icons

## Building Shopify Apps
- Use Polaris + App Bridge + App Design Guidelines
- Create streamlined experience consistent with Shopify admin
- Apps distributed through Shopify App Store
