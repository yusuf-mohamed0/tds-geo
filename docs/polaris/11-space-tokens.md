# Space Tokens

Spacing scale in Polaris. Use `--p-space-{n}` CSS custom properties.

| Token | Value | Typical Use |
|-------|-------|-------------|
| `--p-space-025` | 1px | Hairline borders |
| `--p-space-050` | 2px | Small borders |
| `--p-space-100` | 4px | Tiny gaps |
| `--p-space-200` | 8px | Button gaps, tight spacing |
| `--p-space-300` | 12px | Compact spacing |
| `--p-space-400` | 16px | Card padding, default gap |
| `--p-space-500` | 20px | Section spacing |
| `--p-space-600` | 24px | Large gaps |
| `--p-space-800` | 32px | Page margins |
| `--p-space-1000` | 40px | Section margins |
| `--p-space-1200` | 48px | Large section spacing |
| `--p-space-1600` | 64px | Page section spacing |
| `--p-space-2000` | 80px | Extra large spacing |
| `--p-space-2400` | 96px | Maximum spacing |
| `--p-space-2800` | 112px | Hero spacing |
| `--p-space-3200` | 128px | Maximum hero spacing |

## Component Defaults
- `--p-space-button-group-gap`: var(--p-space-200)
- `--p-space-card-gap`: var(--p-space-400)
- `--p-space-card-padding`: var(--p-space-400)
- `--p-space-table-cell-padding`: var(--p-space-150)
