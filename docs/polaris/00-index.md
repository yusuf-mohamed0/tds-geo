# Polaris Design System for React

Polaris is the design system for the Shopify admin - the shared language that guides how we build high-quality merchant experiences.

## Key Sections
- Getting Started: `/getting-started`
- Foundations: `/foundations` (accessibility, currency formatting, info architecture, i18n)
- Components: `/components` (reusable building blocks)
- Patterns: `/patterns` (preferred solutions to common merchant goals)
- Tokens: `/tokens` (design decisions for color, spacing, typography, etc.)
- Icons: `/icons` (400+ commerce-focused icons)

Source: https://polaris-react.shopify.com/
