## Identity

```
  <YKS />
   YUSUF KO STA
  Code. Build. Ship.™
```

The brand mark `<YKS />` is a self-closing HTML tag where:
- **Y** — Yusuf
- **K** — KO
- **S** — STA
- **< />** — The developer spirit: open to learn, closed to ship

---

## Logo Specification

### Primary Mark
```
<YKS />
```

The brackets represent the developer's craft — every project opens with `<` and ships with `/>`. The tag is self-closing: self-contained, complete, production-ready.
