## Known API Limitation

The TDS Geo WordPress connector's `Sync::STATUS_MAP` maps agent statuses to WordPress statuses:
- `'published' → 'publish'`
- But passing `'publish'` directly fails through to `'draft'`

Also, any PUT operation without explicit `post_type` defaults to `'post'`, overwriting `'product'`.
