## Technical SEO Recommendations

### Immediate (Month 1)
1. Install RankMath or Yoast SEO plugin
2. Add meta descriptions to all 5 pages
3. Generate and submit XML sitemap to Google Search Console
4. Register domain in Google Search Console
5. Install GA4 tracking

### Short-Term (Months 2-3)
6. Add LocalBusiness schema markup (address, phone, hours, certifications)
7. Add Product schema for key brand categories (Generac, Karcher, Powermatic, etc.)
8. Create blog category structure aligning with 4 content pillars
9. Publish 4-8 blog articles (2 per pillar)
10. Enable breadcrumb navigation for SEO

### Medium-Term (Months 3-6)
11. Implement image optimization (WebP, lazy loading)
12. Add caching plugin (WP Rocket, W3 Total Cache, or Flying Press)
13. Set up CDN (Cloudflare recommended — free tier)
14. Build backlinks from brand partner websites
15. Claim and optimize Google Business Profile

### Long-Term (Months 6-12)
16. Build category-specific landing pages for major brands
17. Create downloadable resources (sizing guides, checklists)
18. Consider adding user reviews/testimonials with schema
19. Build industry-specific pillar pages for deeper topical authority
20. Monitor and improve Core Web Vitals

## Content Workflow Recommendation

1. **Weekly Cadence:** 1 article per week (Thursday publishing, per TDS schedule)
2. **Article Format:** 1500-2000 words, EEAT framework, original photography where possible
3. **Approval:** Manual review before publish (no auto-publish initially)
4. **Distribution:** Share to LinkedIn after publishing
5. **Measurement:** Track rankings for target keywords monthly via Google Search Console
