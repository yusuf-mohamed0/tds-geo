# Kivo Brand Kit

Kivo is the master brand. Kivo OS is the command center. Kivo Geo is the GEO/content/commerce product. Kivo Pulse is health and monitoring. Kivo Vault is secure files and credentials.

## Source Of Truth

- React brand constants: `frontend/src/brand/kivo.ts`
- Tailwind palette: `frontend/tailwind.config.js`
- App CSS + Polaris bridge: `frontend/src/index.css`
- Static marketing CSS: `backend/public/css/brand.css`
- Shared design tokens: `assets/brand.css` and `backend/public/assets/brand.css`
- Browser/PWA manifest: `frontend/public/site.webmanifest`

## Logos And Icons

- SVG browser/PWA mark: `frontend/public/assets/kivo-mark.svg`
- Backend-served SVG mark: `backend/public/assets/kivo-mark.svg`
- Favicon entries: `frontend/public/favicon.svg` and `backend/public/favicon.svg`
- Shopify listing icons: `app-store-submission/screenshots/app-icon-square.png` and `app-store-submission/screenshots/app-icon-square-dark.png`

## Usage Rules

- Use `Kivo OS` for the admin command center.
- Use `Kivo Geo` for Shopify, WordPress, Next.js, and GEO content features.
- Use `Kivo Pulse` for health and heartbeat pages/emails.
- Keep compatibility identifiers such as `/api/kivo`, `KIVO_*`, and `X-Kivo-Key` until a migration plan exists.
- Use signal green for primary actions, active navigation, status highlights, and key data accents.
- Use Lucide icons in React and Font Awesome only on static pages.
